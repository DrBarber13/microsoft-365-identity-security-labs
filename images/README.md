# Public-evidence policy

Original screenshots are intentionally excluded because administrative portals can expose tenant names, domains, identities, subscriptions, object IDs, and browser-session details.

The repository instead uses architecture diagrams, decision tables, fictional identities, validation matrices, and investigation timelines. These artifacts demonstrate the reasoning behind identity controls without exposing a real tenant or republishing coursework.

If an independently captured screenshot is added later, it must be reviewed for tenant identifiers, domains, identities, subscription information, object IDs, tokens, notifications, browser profiles, and unrelated page content.
# Image checklist

Use only independently captured and sanitized images:

- Fictional user and group lifecycle
- Delegated role assignment
- Audit or service-health view
- Hybrid authentication status
- PIM eligibility and approval workflow

Remove tenant names, domains, user identities, subscription details, object IDs, timestamps, tokens, and browser profile information.
